[041] (style=Normal, align=JUSTIFY (3)): The rapid growth of computer technology has increased the need for efficient and flexible methods of using multiple operating systems on a single computer system. One of the most widely used technologies for this purpose is virtualization. Virtualization allows users to create and run virtual machines that behave like independent computers within a physical computer. This technology helps users test software, learn operating systems, perform development tasks, and carry out experiments without affecting the main operating system installed on the computer.
[042] (style=Normal, align=JUSTIFY (3)): Oracle VM VirtualBox is one of the most popular open-source virtualization platforms used for creating and managing virtual machines. It provides a simple and user-friendly environment where different operating systems can be installed and executed virtually. VirtualBox supports many operating systems such as Windows, Linux, macOS, and Solaris. It is widely used by students, developers, researchers, and IT professionals because it is free, lightweight, and easy to configure.
[043] (style=Normal, align=JUSTIFY (3)): Ubuntu is a Linux-based open-source operating system developed by Canonical Ltd. Ubuntu is known for its stability, security, and user-friendly graphical interface. It is widely used for programming, server management, cloud computing, networking, cybersecurity, and educational purposes. Ubuntu also provides regular updates, strong community support, and access to thousands of free software packages. Because of its simplicity and reliability, Ubuntu has become one of the most commonly used Linux distributions around the world.
[044] (style=Normal, align=JUSTIFY (3)): The purpose of this project is to install Ubuntu 26.04 on VirtualBox and study the working of virtualization technology. Instead of installing Ubuntu directly on the computer hardware, the operating system is installed inside a virtual machine. This approach allows the user to run Ubuntu safely without making permanent changes to the host operating system. The project demonstrates how a virtual environment can be created by allocating system resources such as RAM,  processor cores, and storage space to the virtual machine.

After the virtual machine setup is completed, the Ubuntu operating system is installed using the ISO image file as the bootable media. Once the installation is successful, additional configurations such as Guest Additions installation, software updates, and basic Linux commands can be performed.
[049] (style=Normal, align=JUSTIFY (3)): This project is important because virtualization has become a key technology in modern computing environments. By learning how to install and use Ubuntu in VirtualBox, users gain practical knowledge of virtual machines and Linux operating systems. It also provides a safe environment for experimentation and learning without the risk of damaging the host computer system.
[050] (style=Normal, align=JUSTIFY (3)): Another advantage of virtualization is resource optimization. VirtualBox also provides features such as snapshots, shared folders, clipboard sharing, and network configuration, making it easier to manage virtual systems. Ubuntu, when combined with VirtualBox, creates an effective platform for learning Linux commands, software development, networking, and system administration.

[124] (style=Heading 1, align=None): SYSTEM DESIGN
[125] (style=Normal, align=JUSTIFY (3)): System design is an important phase in the development and implementation of any computer-based project. It defines the structure, components, workflow, and overall architecture of the system. In this project, the system design focuses on the installation and execution of Ubuntu on a virtual environment using Oracle VM VirtualBox. The design explains how the host operating system, virtualization software, and guest operating system interact with each other to create a fully functional virtual machine.
[126] (style=Normal, align=JUSTIFY (3)): The system is designed in such a way that the host computer acts as the main physical machine, while VirtualBox functions as the virtualization platform responsible for creating and managing virtual machines. Inside the virtual machine, Ubuntu 26.04 is installed as the guest operating system. The entire setup allows users to run Ubuntu independently without modifying or affecting the host operating system.
[127] (style=Normal, align=JUSTIFY (3)): The system design mainly consists of three major components:
[128] (style=Normal, align=JUSTIFY (3)): Host Operating System 
[129] (style=Normal, align=JUSTIFY (3)): Virtualization Layer (VirtualBox) 
[130] (style=Normal, align=JUSTIFY (3)): Guest Operating System (Ubuntu 26.04) 
[131] (style=Normal, align=JUSTIFY (3)): The host operating system provides the physical hardware resources such as processor, RAM, storage, and network connectivity. VirtualBox uses these resources and allocates them to the virtual machine according to the user configuration. Ubuntu operates inside this virtual machine environment as if it were running on a separate physical computer.
[132] (style=Normal, align=JUSTIFY (3)): The architecture of the system ensures resource isolation, flexibility, and safe experimentation. The user can allocate specific memory size, storage capacity, processor cores, and display memory to the virtual machine based on system capability. Features such as snapshots, shared folders, clipboard sharing, and network adapters improve usability and communication between the host and guest operating systems.
[133] (style=Normal, align=JUSTIFY (3)): The installation workflow begins with downloading the Ubuntu ISO image file and installing VirtualBox on the host system. A virtual machine is then created with the required hardware configuration. 
[134] (style=Normal, align=JUSTIFY (3)): 
[135] (style=Normal, align=JUSTIFY (3)): The Ubuntu ISO image is attached as a bootable disk, and the installation process is completed inside the virtual machine. After installation, Ubuntu boots independently and provides a Linux desktop environment for users.
[136] (style=Normal, align=JUSTIFY (3)): The designed system provides several advantages such as:
[137] (style=Normal, align=JUSTIFY (3)):  Safe testing environment 
[138] (style=Normal, align=JUSTIFY (3)):  No modification to host operating system 
[139] (style=Normal, align=JUSTIFY (3)):  Easy backup and recovery using snapshots 
[140] (style=Normal, align=JUSTIFY (3)):  Efficient resource utilization 
[141] (style=Normal, align=JUSTIFY (3)):  Support for learning Linux and virtualization 
[142] (style=Normal, align=JUSTIFY (3)):  Ability to run multiple operating systems simultaneously 
[143] (style=Normal, align=JUSTIFY (3)): The system design also includes network configuration using NAT Adapter mode, which allows the Ubuntu virtual machine to access the internet through the host system connection. VirtualBox Guest Additions can be installed to improve graphics performance, enable full-screen mode, and support file sharing between systems.
[144] (style=Normal, align=JUSTIFY (3)): Overall, the system design provides a stable, flexible, and user-friendly virtualization environment for running Ubuntu 26.04 on VirtualBox. The design demonstrates how virtualization technology simplifies operating system installation and management while providing a secure platform for learning, development, and experimentation.
